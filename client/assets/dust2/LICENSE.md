The supplied GLB metadata identifies this author, source and license. The model
has been converted into static buffers and its original PNG textures for this
game. Coordinates are normalized to metres and aligned with the playable
collision geometry; the original mesh topology, UVs and texture images are
retained. Gameplay, collision and navigation data are additions for this game.

Rebuild using `python scripts/import-dust2.py /path/to/de_dust2_-_cs_map.glb`.
